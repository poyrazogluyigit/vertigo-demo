## Notes

**A Note On Editable Wheel Content:** On earlier versions of the demo, wheel contents are generated randomly per level from a global reward pool. However, to better line up with the requirements of the demo, I have fixed the reward pool to 3 pools of 8 possible rewards, one pool per wheel type. This is done to comply with demo requirements, with the belief that more complex approaches might be too much for a design project.
